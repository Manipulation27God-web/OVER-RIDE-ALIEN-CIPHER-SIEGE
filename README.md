# OVER-RIDE-ALIEN-CIPHER-SIEGE
OVER-RIDE is an intense top-down alien shooter built in Python using Pygame and compiled to a Windows .exe. Featuring real-time cipher ammo swapping and tactical room-breach puzzles under heavy fire, the game delivers fast arcade action. Runs 100% offline with zero telemetry. Windows might flag it for being an "exe" click on MORE INFO then RUN ANYWAY. As the file is above 25 mb it cannot be uploaded on github so check it out at itch.io "https://dhruv-karanji.itch.io/over-ride"
